# Plan 02-01: SQL AST Parser & Pushdown Predicate Compiler

<objective>
Build the SQL parser and predicate pushdown compiler using sqlglot to analyze incoming queries, resolve table aliases against the UnifiedCatalogRegistry, isolate single-table filters, and transpile source-specific subqueries.
</objective>

<threat_model>
### Trust Boundaries
- Consumer Query Input -> SQLParser (AST Parsing)
- PushdownCompiler -> Remote Database Drivers

### STRIDE Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering / SQL Injection | SQLParser | mitigate | Parse through AST representation; reject raw string concatenation; enforce structured expression compilation |
| T-02-02 | Denial of Service | SQLParser | mitigate | Enforce maximum SQL text length (e.g., 50KB) and query complexity checks |
| T-02-03 | Information Disclosure | PushdownCompiler | mitigate | Sanitize database schema and table names against UnifiedCatalogRegistry before compiling subqueries |
</threat_model>

  <action>
    Create backend/app/federation/parser.py:
    - Define ParsedQuery model (tables: list[TableReference], aliases: dict[str, str], is_multi_source: bool, columns_by_alias: dict[str, set[str]], ast: exp.Expression).
    - Implement SQLParser.parse(sql: str, catalog: UnifiedCatalogRegistry) -> ParsedQuery:
      - Uses sqlglot.parse_one(sql).
      - Resolves 3-part names (e.g. adls_lake.equity.trades) and maps aliases.
      - Groups tables by datasource name to classify as single-source vs. multi-source.
      - Extracts columns referenced by each table alias across SELECT, WHERE, JOIN ON, GROUP BY, ORDER BY.
    - Export parser in backend/app/federation/__init__.py.
  </action>
  <verify>
    Run pytest tests/test_sql_parser.py -v.
  </verify>
  <done>

<task type="auto">
  <name>Implement Pushdown Predicate Compiler</name>
  <files>backend/app/federation/compiler.py</files>
  <action>
    Create backend/app/federation/compiler.py:
    - Define SubqueryPlan model (datasource_name: str, schema_name: str, table_name: str, alias: str, projected_columns: list[str], sql: str, dialect: str).
    - Implement PushdownCompiler.compile(parsed: ParsedQuery) -> tuple[dict[str, SubqueryPlan], exp.Expression]:
      - Separates isolated predicates (predicates targeting a single alias) from mixed predicates.
      - For each alias, synthesizes a clean SELECT query with required columns and isolated WHERE predicates.
      - Transpiles to target dialect: 'oracle' for Oracle, 'tsql' for SQL Server, 'duckdb' for ADLS Iceberg/others.
      - Rewrites the root AST to replace original table names with internal view names (__subq_{alias}) and retains only mixed predicates and cross-source joins/aggregations.
  </action>
  <verify>
    Run pytest tests/test_pushdown_compiler.py -v.
  </verify>
  <done>
    PushdownCompiler extracts isolated WHERE conditions, produces dialect-compliant subqueries, and generates a rewritten root join AST for DuckDB.
  </done>
</task>
