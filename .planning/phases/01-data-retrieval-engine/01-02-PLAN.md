# Plan 01-02: Apache Iceberg ADLS Gen2 & Cosmos DB Connectors

<objective>
Implement the high-performance Apache Iceberg connector for ADLS Gen2 capable of inspecting metadata manifests, pruning files, and executing zero-copy DuckDB vectorized scans, alongside the Azure Cosmos DB connector with partition-aware schema sampling.
</objective>

<threat_model>
### Trust Boundaries
- Platform Service -> ADLS Gen2 Storage Account
- Platform Service -> Azure Cosmos DB Account

### STRIDE Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | Tampering | IcebergADLSConnector | mitigate | Connect to ADLS with Storage Blob Data Reader role only; scan in read-only mode |
| T-01-05 | Denial of Service | CosmosDBConnector | mitigate | Cap document sampling to TOP 50 items and enforce partition-key queries to prevent RU exhaustion |
| T-01-06 | Information Disclosure | Iceberg Snapshots | mitigate | Expose snapshot metadata without leaking underlying storage SAS tokens or credentials in responses |
</threat_model>

<tasks>

<task type="auto">
  <name>Implement Apache Iceberg ADLS Gen2 Connector</name>
  <files>backend/app/connectors/iceberg_adls.py</files>
  <action>
    Create backend/app/connectors/iceberg_adls.py inheriting BaseConnector:
    - Support ADLS Gen2 connection configuration (storage_account, container, credential_secret_name, catalog_type).
    - Use pyiceberg for catalog inspection (load_catalog).
    - Implement introspect_schemas() and introspect_tables().
    - Implement get_table_schema() extracting column names, data types, nullability, and partition spec fields from Iceberg metadata.
    - Implement get_snapshots() returning snapshot IDs, timestamps, and commit summaries for financial auditing.
    - Implement execute_query() executing DuckDB SELECT * FROM iceberg_scan('...') and converting relation to pyarrow.Table.
  </action>
  <verify>
    Run pytest tests/test_iceberg_adls.py -v validating schema introspection and Iceberg table query execution.
  </verify>
  <done>
    IcebergADLSConnector successfully inspects Iceberg metadata manifests, lists audit snapshots, and streams data via DuckDB iceberg_scan to pyarrow.Table.
  </done>
</task>

<task type="auto">
  <name>Implement Azure Cosmos DB Connector</name>
  <files>backend/app/connectors/cosmos.py</files>
  <action>
    Create backend/app/connectors/cosmos.py inheriting BaseConnector:
    - Support Cosmos DB endpoint, key, and database configuration.
    - Implement introspect_schemas() (returning databases) and introspect_tables() (returning containers).
    - Implement get_table_schema():
      - Read container partition key definition (e.g. /portfolioId).
      - Query top 50 documents (SELECT TOP 50 * FROM c) to infer column names and JSON types without incurring high RU costs.
      - Mark partition key columns with is_partition_key=True.
    - Implement execute_query(sql, limit) executing parameterized Cosmos SQL and projecting results into a pyarrow.Table.
  </action>
  <verify>
    Run pytest tests/test_cosmos.py -v confirming container discovery, partition key detection, and schema inference.
  </verify>
  <done>
    CosmosDBConnector discovers containers, correctly identifies partition key paths, samples documents safely, and converts query results to pyarrow.Table.
  </done>
</task>
