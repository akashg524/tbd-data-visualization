# Plan 01-03: Relational Read-Only Connectors (Oracle, MSSQL, Azure SQL) & Unified Catalog Registry

<objective>
Implement high-performance read-only connectors for Oracle and SQL Server/Azure SQL with strict isolation guardrails, and build the central Unified Schema Catalog Registry that indexes all multi-store schemas under a single virtual namespace.
</objective>

<threat_model>
### Trust Boundaries
- Platform Service -> On-Premises Corporate Network (Oracle / SQL Server)
- Client Query API -> UnifiedCatalogRegistry

### STRIDE Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-07 | Tampering | OracleConnector | mitigate | Execute ALTER SESSION SET TRANSACTION READ ONLY on session initialization to physically block DML |
| T-01-08 | Tampering / Lock | SQLServerConnector | mitigate | Enforce ApplicationIntent=ReadOnly and READ UNCOMMITTED isolation to prevent write routing or lock contention |
| T-01-09 | Information Disclosure | UnifiedCatalogRegistry | mitigate | Filter out internal database system tables (SYS, SYSTEM, sys.*) from metadata tree |
</threat_model>

<task type="auto">
  <name>Implement Oracle Read-Only Connector</name>
  <files>backend/app/connectors/oracle.py</files>
  <action>
    Create backend/app/connectors/oracle.py inheriting BaseConnector:
    - Connect using oracledb in pure thin mode (no Instant Client binaries needed).
    - On connection checkout, execute ALTER SESSION SET TRANSACTION READ ONLY to enforce read-only safety.
    - Implement introspect_schemas() querying distinct OWNER from ALL_TABLES.
    - Implement introspect_tables(schema) querying ALL_TABLES (filtering out system schemas like SYS, SYSTEM).
    - Implement get_table_schema(schema, table) querying ALL_TAB_COLUMNS and ALL_CONSTRAINTS to extract column types, nullability, and primary key flags.
    - Implement execute_query(sql, limit) executing read-only SQL and fetching results directly into pyarrow.Table.
  </action>
  <verify>
    Run pytest tests/test_relational_connectors.py -k oracle -v.
  </verify>
  <done>
    OracleConnector enforces read-only session isolation, discovers non-system schemas and tables, and returns query results as pyarrow.Table.
  </done>
</task>

<task type="auto">
  <name>Implement SQL Server & Azure SQL Read-Only Connector</name>
  <files>backend/app/connectors/sqlserver.py</files>
  <action>
    Create backend/app/connectors/sqlserver.py inheriting BaseConnector:
    - Connect using pymssql / SQLAlchemy with ApplicationIntent=ReadOnly in connection properties to target AlwaysOn secondary replicas.
    - Set transaction isolation level to READ UNCOMMITTED for non-blocking analytical reads.
    - Implement introspect_schemas() querying sys.schemas.
    - Implement introspect_tables(schema) querying INFORMATION_SCHEMA.TABLES.
    - Implement get_table_schema(schema, table) querying INFORMATION_SCHEMA.COLUMNS and INFORMATION_SCHEMA.KEY_COLUMN_USAGE.
    - Implement execute_query(sql, limit) converting results to pyarrow.Table.
  </action>
  <verify>
    Run pytest tests/test_relational_connectors.py -k sqlserver -v.
  </verify>
  <done>
    SQLServerConnector routes to secondary read replicas with non-blocking isolation and converts result sets to pyarrow.Table.
  </done>
</task>

<task type="auto">
  <name>Implement Unified Schema Catalog Registry</name>
  <files>backend/app/catalog.py</files>
  <action>
    Create backend/app/catalog.py:
    - UnifiedCatalogRegistry:
      - register_datasource(name: str, connector: BaseConnector)
      - unregister_datasource(name: str)
      - list_datasources() -> list[str]
      - get_connector(name: str) -> BaseConnector
      - resolve_table(full_path: str) -> tuple[BaseConnector, str, str]: parses datasource.schema.table
      - refresh_catalog(datasource_name: str | None = None): asynchronously introspects and caches table metadata across all sources.
      - get_unified_tree() -> dict: returns nested hierarchical structure for Power BI / UI navigation.
      - Thread-safe caching with async locks.
  </action>
  <verify>
    Run pytest tests/test_catalog.py -v validating catalog registration, full path resolution, and metadata tree export.
  </verify>
  <done>
    UnifiedCatalogRegistry indexes registered datasources, provides hierarchical tree navigation, and resolves cross-source table paths.
  </done>
</task>
