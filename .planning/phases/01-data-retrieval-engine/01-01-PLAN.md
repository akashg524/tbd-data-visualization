# Plan 01-01: Credential Vault & Pluggable Base Connector Architecture

<objective>
Build the secure credential management system integrating Azure Key Vault with local mock/env fallback, and establish the abstract `BaseConnector` lifecycle, type definitions, and schema metadata data models.
</objective>

<must_haves>
- `CredentialVault` class resolves secrets from Azure Key Vault when configured, or transparently falls back to local `.env`/environment variables without erroring when Azure is offline.
- Pydantic models for `TableMetadata`, `ColumnMetadata`, `TableSchema`, `ConnectionConfig`, and `ConnectionStatus`.
- `BaseConnector` abstract base class defining standard asynchronous lifecycle methods: `test_connection()`, `introspect_schemas()`, `introspect_tables()`, `get_table_schema()`, and `execute_query()`.
- 100% test coverage with automated unit tests for vault resolution and base connector contracts.
</must_haves>

<tasks>

<task type="auto">
  <name>Implement Credential Vault with Azure Key Vault & Mock Fallback</name>
  <files>backend/app/vault.py</files>
  <action>
    Create `backend/app/vault.py` defining `CredentialVault`.
    - If `AZURE_KEYVAULT_URL` is set, initialize `SecretClient` with `DefaultAzureCredential`.
    - Provide `get_secret(key: str, default: str | None = None) -> str`.
    - Implement caching of resolved secrets with thread-safe dictionary.
    - Provide fallback to local environment variables and encrypted local secrets using `cryptography.fernet`.
    - Ensure zero exception crashes when running offline without active Azure credentials.
  </action>
  <verify>
    Run `pytest tests/test_vault.py -v` to confirm secret resolution, local fallback, and caching.
  </verify>
</task>

<task type="auto">
  <name>Define Connector Data Models and Abstract BaseConnector</name>
  <files>
    backend/app/connectors/models.py
    backend/app/connectors/base.py
    backend/app/connectors/__init__.py
  </files>
  <action>
    Create `backend/app/connectors/models.py` with Pydantic v2 models:
    - `DataType`: string, integer, float, decimal, boolean, timestamp, date, json, binary.
    - `ColumnMetadata`: name, data_type, nullable, is_primary_key, is_partition_key, comment.
    - `TableMetadata`: name, schema_name, row_count_estimate, format_type, comment.
    - `TableSchema`: table_name, schema_name, columns: list[ColumnMetadata], partition_keys: list[str].
    - `ConnectionStatus`: is_connected, latency_ms, error_message, server_version.
    
    Create `backend/app/connectors/base.py` with `BaseConnector(ABC)`:
    - `__init__(config: ConnectionConfig, vault: CredentialVault | None = None)`
    - Abstract async methods: `connect()`, `disconnect()`, `test_connection()`, `introspect_schemas()`, `introspect_tables()`, `get_table_schema()`, and `execute_query(sql, limit) -> pyarrow.Table`.
    - Enforce read-only constraint property `is_read_only = True`.
    
    Export types in `backend/app/connectors/__init__.py`.
  </action>
  <verify>
    Run `pytest tests/test_base_connector.py -v` verifying model serialization, validation, and abstract base class behaviors.
  </verify>
</task>
