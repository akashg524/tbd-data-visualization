# Plan 05-02: SQLGlot AST RLS Rewriter & Pluggable ACL Filter Injection Engine

<objective>
Implement an AST-level query transformer using SQLGlot that intercepts incoming SQL queries, validates Gate 1 table RBAC permissions, and transparently injects row-level security predicates (direct column match, name-to-ID translations, and composite rules) across joins, CTEs, and subqueries before pushdown query planning.
</objective>

<threat_model>
### Trust Boundaries
- User Input SQL -> SQLGlot Parser
- Raw Query AST -> Security AST Transformer -> Pushdown Compiler

### STRIDE Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02 | Elevation of Privilege | ASTRewriter | mitigate | Walk all AST nodes recursively; inject RLS predicates into inner CTEs, subqueries, and set operations (`UNION`, `INTERSECT`) |
| T-05-03 | Elevation of Privilege | ASTRewriter | mitigate | Qualify all injected predicate columns with explicit table aliases to prevent ambiguity and shadowing in multi-table joins |
| T-05-07 | Elevation of Privilege | ASTRewriter | mitigate | Validate Gate 1 RBAC permissions on all referenced tables before rewriting; fail fast if user lacks required role |
</threat_model>

  <action>
    Create backend/app/federation/rewriter.py:
    - Implement `ASTRewriter` class:
      - Method `rewrite(sql: str, context: SecurityContext, catalog: UnifiedCatalogRegistry, registry: GovernancePolicyRegistry | None = None) -> tuple[str, list[str]]`:
        - Parses `sql` into SQLGlot AST.
        - If query has no table references (scalar query), returns `(sql, [])`.
        - Traverses AST to locate all `exp.Table` nodes.
        - For each table:
          - Resolves table path (e.g. `catalog.schema.table` or `schema.table`).
          - Matches policy in `GovernancePolicyRegistry`.
          - If policy exists and user is NOT exempt:
            - **Gate 1 Validation**: Check `policy.required_roles`. If user lacks required roles, raise `PermissionError(f"Access denied: Table '{table_path}' requires one of roles: {policy.required_roles}")`.
            - **Gate 2 ACL Predicate Synthesis**: If `policy.gate == GateType.RBAC_AND_ACL`:
              - For each `AclRule` in `policy.acl_rules`:
                - Extracts claim values from `context` using `context.get_effective_claims(rule.claim_field)`.
                - If values are empty and `policy.fail_closed`:
                  - Injects `exp.Literal.number(1).eq(exp.Literal.number(0))` (`1 = 0`).
                  - Records rule in `rls_rules_applied`.
                  - Continue.
                - If `rule.strategy == PolicyStrategy.TRANSLATION`:
                  - If `rule.lookup_map`: translates claim values (e.g. `["US", "EMEA"]` -> `[1, 2]`).
                  - If lookup table/cache: resolves IDs from reference data.
                  - If translated values empty: injects `1 = 0`.
                - Builds predicate:
                  - For single value: `col.eq(val)`
                  - For multiple values: `col.isin(*values)`
                - Qualifies column with table's alias or table name identifier.
                - Finds table's enclosing `exp.Select` and appends predicate to `WHERE` clause using `node.where(predicate, copy=False)`.
                - Records rule in `rls_rules_applied`.
        - Emits and returns `(secured_sql, rls_rules_applied)`.

    Export `ASTRewriter` in `backend/app/federation/__init__.py`.
  </action>
  <verify>
    Run python -c "from app.federation import ASTRewriter; print('ASTRewriter ready')".
  </verify>
  <done>
    AST rewriter validates Gate 1 RBAC, injects alias-qualified RLS predicates, and supports direct and translation strategies.
  </done>
