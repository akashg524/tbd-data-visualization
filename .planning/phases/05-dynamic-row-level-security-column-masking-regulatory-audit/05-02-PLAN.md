# Plan 05-02: SQLGlot AST RLS Rewriter & Column-Level Dynamic Data Masking Engine

<objective>
Implement an AST-level query transformer using SQLGlot that intercepts incoming SQL queries and transparently injects row-level security predicates and column-level dynamic data masks before pushdown query planning and join execution.
</objective>

<threat_model>
### Trust Boundaries
- User Input SQL -> SQLGlot Parser
- Raw Query AST -> Security AST Transformer -> Pushdown Compiler

### STRIDE Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02 | Elevation of Privilege | ASTRewriter | mitigate | Walk all AST nodes recursively; inject RLS predicates into inner CTEs, subqueries, and set operations (`UNION`, `INTERSECT`) |
| T-05-03 | Elevation of Privilege | ASTRewriter | mitigate | Qualify all injected predicate columns with explicit table aliases to prevent ambiguity and shadowing in multi-table joins |
| T-05-04 | Information Disclosure | ASTRewriter | mitigate | Expand `SELECT *` wildcards against catalog schemas to guarantee masked columns are replaced with masking expressions |
</threat_model>

<task type="auto">
  <name>Implement SQLGlot AST Security Rewriter</name>
  <files>
    backend/app/federation/rewriter.py
    backend/app/federation/__init__.py
  </files>
  <action>
    Create backend/app/federation/rewriter.py:
    - Implement `ASTRewriter` class:
      - Method `rewrite(sql: str, context: SecurityContext, catalog: UnifiedCatalogRegistry, registry: GovernancePolicyRegistry | None = None) -> tuple[str, list[str], list[str]]`:
        - Parses `sql` into SQLGlot AST.
        - If query has no table references (scalar query), returns original SQL.
        - Traverses AST to locate all `exp.Table` nodes.
        - For each table:
          - Matches policy in `GovernancePolicyRegistry`.
          - If policy exists and user is NOT exempt:
            - Extracts allowed claim values from `context` (e.g. `context.trading_desks`).
            - If allowed values are empty: injects `exp.Literal.number(1).eq(exp.Literal.number(0))` (fail-closed `1 = 0`).
            - Else: builds `col.isin(*allowed_values)` or `col.eq(allowed_val)`.
            - Qualifies column with table's alias or raw table name.
            - Finds table's enclosing `exp.Select` or `exp.Query` and appends predicate to `WHERE` clause using `node.where(predicate, copy=False)`.
            - Records rule in `rls_rules_applied`.
        - Expands wildcards and applies column masking:
          - For each `exp.Select`:
            - If `select.is_star`:
              - Inspects referenced tables in `select`, retrieves schema columns from `catalog`.
              - Replaces `*` with explicit list of column expressions.
            - For each column projection:
              - Checks if column matches a `ColumnMaskRule` on a referenced governed table.
              - If matched and user is NOT exempt:
                - Generates masking SQL expression (e.g. `CONCAT('***-**-', SUBSTRING(CAST(col AS VARCHAR), -4, 4)) AS alias`).
                - Replaces projection expression in AST.
                - Records column in `columns_masked`.
        - Emits and returns `(secured_sql, rls_rules_applied, columns_masked)`.

    Export `ASTRewriter` in `backend/app/federation/__init__.py`.
  </action>
  <verify>
    Run python -c "from app.federation import ASTRewriter; print('ASTRewriter ready')".
  </verify>
  <done>
    AST rewriter injects RLS predicates, expands wildcards, and masks sensitive columns.
  </done>
</task>
