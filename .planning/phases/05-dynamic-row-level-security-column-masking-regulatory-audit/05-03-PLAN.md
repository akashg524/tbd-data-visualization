# Plan 05-03: Cross-Protocol Policy Enforcement & SOX/FINRA Regulatory Audit Trail

<objective>
Wire the AST security rewriter and governance context into the query execution engine, isolate result caches with security fingerprints, enforce RLS across all client protocols (REST, OData, PGWire, Arrow Flight), surface transparent explain metrics, and emit immutable structured audit events for Microsoft Sentinel and SOX/FINRA compliance.
</objective>

<threat_model>
### Trust Boundaries
- Untrusted Client Request -> Serving Protocol -> SecurityContext
- SecurityContext -> ResultCache Fingerprint
- Query Execution -> AuditLogger Output (Azure Event Hub / Microsoft Sentinel)

### STRIDE Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information Disclosure | ResultCache | mitigate | Key cache entries by `hash(sql + ":" + security_context.fingerprint)` to guarantee zero cross-desk data contamination |
| T-05-05 | Repudiation | AuditLogger | mitigate | Emit structured JSON audit logs in try/finally blocks capturing user ID, original/rewritten SQL, tables accessed, row counts, and duration |
</threat_model>

  <name>Implement Security Cache Isolation and Event Hub / Sentinel Audit Logger</name>
  <files>
    backend/app/cache.py
    backend/app/auth/audit.py
    backend/app/federation/executor.py
  </files>
  <action>
    Update backend/app/cache.py:
    - Update `ResultCache.get(sql: str, security_fingerprint: str = "") -> pa.Table | None`:
      - Key generation incorporates `security_fingerprint`: `f"{sql}::fprint={security_fingerprint}"`.
    - Update `ResultCache.set(sql: str, table: pa.Table, security_fingerprint: str = "")`.

    Create backend/app/auth/audit.py:
    - Implement `AuditLogger`:
      - Method `log_query_execution(context: SecurityContext, original_sql: str, secured_sql: str, rls_filters: list[str], sources: list[str], duration_ms: float, row_count: int, cache_hit: bool, protocol: str, status: str = "SUCCESS")`.
      - Method `log_export_event(context: SecurityContext, format: str, row_count: int, filename: str)`.
      - Emits structured JSON events via `structlog.get_logger("audit")`.
      - Supports async publishing to Azure Event Hub / Microsoft Sentinel (when `EVENT_HUB_CONNECTION_STRING` is configured), with local structured logging fallback.

    Update backend/app/federation/executor.py:
    - Extend `ExecutionMetrics`:
      - Add `applied_rls_filters: list[str] = field(default_factory=list)`
      - Add `secured_sql: str | None = None`
    - Update `FederatedExecutor.execute`:
      - Accept `security_context: SecurityContext | None = None`.
      - If `security_context` is present:
        - Call `ASTRewriter.rewrite(sql, security_context, self.catalog)` -> `(secured_sql, rls_rules)`.
        - Check `self.cache.get(sql, security_fingerprint=security_context.fingerprint)`.
        - If cache miss: execute query using `secured_sql`.
        - Store in `self.cache.set(sql, table, security_fingerprint=security_context.fingerprint)`.
        - Populate `metrics.applied_rls_filters = rls_rules` and `metrics.secured_sql = secured_sql`.
        - Record audit event using `AuditLogger`.
      - If `security_context` is absent: execute standard `sql`.
  </action>
  <verify>
    Run python -c "from app.auth.audit import AuditLogger; from app.cache import ResultCache; print('Cache and Audit ready')".
  </verify>
  <done>
    Result cache enforces fingerprint isolation and audit logging captures query execution provenance.
  </done>
</task>
