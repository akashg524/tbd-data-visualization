# Plan 05-01: Entra ID Governance Claim Mapping & Two-Gate Declarative Policy Engine

<objective>
Implement the enterprise governance foundation: parse fine-grained security claims from Entra ID tokens into a normalized `SecurityContext` with hierarchical priority resolution, compute deterministic security cache fingerprints, and establish a declarative `GovernancePolicyRegistry` supporting both Gate 1 (Pure Azure RBAC) and Gate 2 (Fine-grained ACL/RLS with pluggable translation strategies).
</objective>

<threat_model>
### Trust Boundaries
- Untrusted JWT Claims -> SecurityContext Parser
- SecurityContext -> Cache Fingerprint Generator
- SecurityContext -> Gate 1 RBAC Validator & Gate 2 ACL Resolver

### STRIDE Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information Disclosure | SecurityContext.fingerprint | mitigate | Hash all normalized security constraints (`roles`, `desks`, `regions`, `accounts`, `clearance`) so cache entries can never cross tenant, desk, or account boundaries |
| T-05-06 | Spoofing | EntraIDAuthenticator | mitigate | Extract claims strictly from verified RS256 token payloads, falling back to safe dev defaults only when `auth_enabled=False` |
| T-05-07 | Elevation of Privilege | GovernancePolicyRegistry | mitigate | Enforce Gate 1 RBAC check before query execution, rejecting unauthorized tables with 403 Forbidden |
</threat_model>

    - Define `GateType(StrEnum)`: `RBAC_ONLY` = "rbac_only", `RBAC_AND_ACL` = "rbac_and_acl".
    - Define `PolicyStrategy(StrEnum)`:
      - `DIRECT` = "direct" (claim values match table column directly)
      - `TRANSLATION` = "translation" (translates text names to IDs via dictionary or lookup)
      - `RELATIONSHIP` = "relationship" (translates via dimension foreign-key relationship)
    - Define `AclRule`:
      - `claim_field: str` (e.g. `trading_desks`, `regions`, `allowed_accounts`)
      - `target_column: str` (e.g. `desk_code`, `region_id`, `account_no`)
      - `strategy: PolicyStrategy = PolicyStrategy.DIRECT`
      - `lookup_map: dict[str, Any] | None = None` (for in-memory dictionary translation)
      - `lookup_table: str | None = None` (for DimensionCache lookup)
      - `lookup_key_column: str | None = None` (e.g. `region_name`)
      - `lookup_val_column: str | None = None` (e.g. `region_id`)
    - Define `TableSecurityPolicy`:
      - `table_pattern: str` (e.g. `*.trades`, `equity.trades`, `*.mna_deals`)
      - `gate: GateType = GateType.RBAC_AND_ACL`
      - `required_roles: list[str] = Field(default_factory=list)`
      - `acl_rules: list[AclRule] = Field(default_factory=list)`
      - `acl_combination: str = "AND"` ("AND" or "OR")
      - `fail_closed: bool = True` (if user has role but zero matching ACL claims, inject 1=0 / return 0 rows)
      - `exempt_roles: set[str] = Field(default_factory=lambda: {"ComplianceAdmin", "SecurityAdmin"})`
    - Define `SecurityContext`:
      - `user_id: str`
      - `username: str`
      - `roles: list[str]`
      - `groups: list[str]`
      - `trading_desks: list[str]`
      - `regions: list[str]`
      - `allowed_accounts: list[str]`
      - `clearance_level: str` (default `"STANDARD"`)
      - `attributes: dict[str, Any]`
      - `hierarchical_priority: bool = True`
      - `fingerprint: str` property: SHA-256 hash of sorted roles, trading_desks, regions, allowed_accounts, and clearance_level.
      - Helper methods:
        - `is_exempt(exempt_roles: set[str]) -> bool`
        - `has_any_role(required_roles: list[str]) -> bool`
        - `get_effective_claims(claim_field: str) -> list[Any]` (applies hierarchical priority: desk overrides region when specified)
    - Define `GovernancePolicyRegistry`:
      - Singleton managing registered table policies.
      - Methods:
        - `register_policy(policy: TableSecurityPolicy) -> None`
        - `get_policy_for_table(table_path: str) -> TableSecurityPolicy | None`
        - `validate_rbac_gate(table_path: str, context: SecurityContext) -> bool` (Gate 1 check)
      - Pre-register standard enterprise policies:
        - `*.mna_deals`: `GateType.RBAC_ONLY`, `required_roles=["MNA_Auditor", "SecurityAdmin"]`.
        - `*.trades`: `GateType.RBAC_AND_ACL`, `required_roles=["FinancialAnalyst", "Trader"]`, ACL rules:
          - `trading_desks` -> `desk_code` (DIRECT)
          - `regions` -> `region_id` (TRANSLATION via `{"US": 1, "EMEA": 2, "APAC": 3, "LATAM": 4}`)
          - `allowed_accounts` -> `account_no` (DIRECT)
        - `*.counterparties`: `GateType.RBAC_AND_ACL`, `required_roles=["FinancialAnalyst"]`, ACL rule:
          - `regions` -> `region_id` (TRANSLATION)
