# Plan 05-01: Entra ID Governance Claim Mapping & Declarative Policy Engine

<objective>
Implement the enterprise governance foundation: parse fine-grained security claims from Entra ID tokens into a normalized `SecurityContext`, compute deterministic security cache fingerprints, and establish a declarative `GovernancePolicyRegistry` for table-level RLS filters and column-level dynamic data masks.
</objective>

<threat_model>
### Trust Boundaries
- Untrusted JWT Claims -> SecurityContext Parser
- SecurityContext -> Cache Fingerprint Generator

### STRIDE Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information Disclosure | SecurityContext.fingerprint | mitigate | Hash all normalized security constraints (`roles`, `desks`, `regions`, `clearance`) so cache entries can never cross tenant or desk boundaries |
| T-05-06 | Spoofing | EntraIDAuthenticator | mitigate | Extract claims strictly from verified RS256 token payloads, falling back to safe dev defaults only when `auth_enabled=False` |
</threat_model>

    Create backend/app/auth/governance.py:
    - Define `MaskingType(StrEnum)`: `PARTIAL`, `EMAIL`, `REDACT`, `HASH`.
    - Define `ColumnMaskRule`:
      - `column_name: str`
      - `mask_type: MaskingType`
      - `params: dict[str, Any]` (e.g. prefix length, suffix length)
      - `exempt_roles: set[str]` (defaults to `{"ComplianceAdmin", "SecurityAdmin"}`)
    - Define `TableSecurityPolicy`:
      - `table_pattern: str` (e.g. `*.trades`, `equity.trades`, `*.counterparties`)
      - `rls_column: str | None = None` (e.g. `desk`, `region`)
      - `rls_claim_field: str | None = None` (e.g. `trading_desks`, `regions`)
      - `column_masks: dict[str, ColumnMaskRule]`
      - `exempt_roles: set[str]` (defaults to `{"ComplianceAdmin", "SecurityAdmin"}`)
    - Define `SecurityContext`:
      - `user_id: str`
      - `username: str`
      - `roles: list[str]`
      - `groups: list[str]`
      - `trading_desks: list[str]`
      - `regions: list[str]`
      - `clearance_level: str` (default `"STANDARD"`)
      - `attributes: dict[str, Any]`
      - `fingerprint: str` property: SHA-256 hash of sorted roles, trading_desks, regions, and clearance_level.
      - Helper method `is_exempt(exempt_roles: set[str]) -> bool`.
    - Define `GovernancePolicyRegistry`:
      - Singleton managing registered table policies.
      - Pre-register standard enterprise policies for financial demo/benchmark data:
        - `*.trades`: RLS on `desk` mapped to `trading_desks`. Mask `counterparty_ssn` (PARTIAL), `trader_email` (EMAIL).
        - `*.counterparties`: RLS on `region` mapped to `regions`. Mask `tax_id` (PARTIAL), `iban` (PARTIAL).
      - Lookup method `get_policy_for_table(table_name: str) -> TableSecurityPolicy | None`.
