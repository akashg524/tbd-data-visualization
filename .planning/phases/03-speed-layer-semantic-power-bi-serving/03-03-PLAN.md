# Plan 03-03: Apache Arrow Flight Server & Columnar Batch Ingestion

<objective>
Implement the Apache Arrow Flight gRPC server for multi-GB/s columnar batch ingestion into Power BI and analytical notebooks, provide chunked REST export endpoints, and manage background server lifecycles in FastAPI.
</objective>

<threat_model>
### Trust Boundaries
- Flight Client / Python / ADBC -> FederatedFlightServer (Port 5005)
- Web Browser / Power BI -> REST Export API (/api/v1/export/query)

### STRIDE Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07 | Denial of Service / Memory Exhaustion | Arrow Flight Server | mitigate | Stream RecordBatches incrementally without collecting all rows into Python memory |
| T-03-08 | Information Disclosure | Flight Descriptors | mitigate | Authenticate tickets and only return authorized datasets |
| T-03-09 | Denial of Service / Connection Leak | Server Lifecycle | mitigate | Ensure graceful shutdown of gRPC and socket listeners on FastAPI exit |
</threat_model>

  <action>
    Create backend/app/serving/flight.py:
    - Implement FederatedFlightServer(fl.FlightServerBase):
      - __init__(host: str = "0.0.0.0", port: int = 5005, executor: FederatedExecutor, catalog: UnifiedCatalogRegistry).
      - do_get(context, ticket: fl.Ticket) -> fl.FlightDataStream:
        - Extracts SQL from ticket bytes.
        - Executes query via FederatedExecutor.
        - Returns fl.RecordBatchStreamReader(arrow_table).
      - list_flights(context, criteria):
        - Yields FlightInfo descriptors for registered catalog tables.
      - get_flight_info(context, descriptor):
        - Returns schema and endpoints for requested flight path.
      - start_background() -> runs server in daemon thread.
      - stop() -> server.shutdown().
    
    Export in backend/app/serving/__init__.py.
    Write tests in tests/test_flight_server.py verifying pyarrow.flight.connect(), list_flights(), and do_get() stream reading.
  </action>
  <verify>
    Run pytest tests/test_flight_server.py -v.
  </verify>
  <done>
    FederatedFlightServer streams columnar Arrow batches over gRPC with zero-copy efficiency.
  </done>
