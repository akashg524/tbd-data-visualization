# Plan 03-02: PostgreSQL Wire Protocol Gateway & Power BI DirectQuery Server

<objective>
Implement the PostgreSQL wire protocol gateway using buenavista to allow Power BI Desktop and Power BI Service to connect natively via DirectQuery without custom drivers, navigate virtual schemas, and execute analytical queries.
</objective>

<threat_model>
### Trust Boundaries
- Power BI Desktop / TCP Clients -> PostgresWireServer (Port 5433)
- PostgresWireServer -> FederatedExecutor & In-Memory DuckDB

### STRIDE Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Denial of Service / Connection Flooding | PostgresWireServer | mitigate | Configure max connection limits and non-blocking threaded socket server |
| T-03-05 | Elevation of Privilege / Injection | Query Interceptor | mitigate | Enforce read-only query parsing through SQLParser before execution |
| T-03-06 | Information Disclosure | Metadata Views | mitigate | Only expose tables registered in UnifiedCatalogRegistry |
</threat_model>

<task type="auto">
  <name>Implement PostgreSQL Wire Protocol Server with Schema Shadowing</name>
  <files>
    backend/app/serving/__init__.py
    backend/app/serving/pgwire.py
  </files>
  <action>
    Create backend/app/serving/pgwire.py:
    - Define FederatedSession(Session):
      - Accepts FederatedExecutor, catalog DuckDB database, and UnifiedCatalogRegistry.
      - execute_sql(sql: str, params=None) -> QueryResult:
        - Check if query is system/metadata (pg_catalog, information_schema, SHOW, version(), current_schema): execute against catalog DuckDB.
        - Check if query is analytical: run through FederatedExecutor.execute(sql) in thread-safe loop.
        - Wrap returned PyArrow Table into DuckDBQueryResult(table.to_reader()).
    - Define FederatedConnection(Connection):
      - Returns standard Postgres parameters (server_version="14.0.federated", client_encoding="UTF8", DateStyle="ISO", standard_conforming_strings="on").
      - new_session() -> FederatedSession.
    - Define PostgresWireServer:
      - __init__(host: str = "0.0.0.0", port: int = 5433, executor: FederatedExecutor, catalog: UnifiedCatalogRegistry).
      - Synchronizes virtual catalog schemas and empty table definitions into catalog DuckDB for information_schema.
      - start(): Starts BuenaVistaServer in a daemon background thread.
      - stop(): Shuts down server cleanly and closes sockets.
    
    Export server in backend/app/serving/__init__.py.
  </action>
  <verify>
    Run pytest tests/test_pgwire_server.py -k connection -v.
  </verify>
  <done>
    PostgresWireServer starts in background, accepts connections, and returns system parameters.
  </done>
</task>
